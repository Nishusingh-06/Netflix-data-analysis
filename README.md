# Netflix-data-analysis 

🎬 Netflix Data Analysis using MySQL
📌 Project Overview

This project focuses on analyzing Netflix movies and TV shows data using MySQL.
The main objective of this project is to perform data cleaning, data exploration, and extract meaningful business insights using SQL queries.

The project includes analysis of:

-Movies vs TV Shows distribution
-Content released over the years
-Top genres available on Netflix
-Country-wise content distribution
-Ratings and duration analysis
-Most frequent directors and actors

🛠️ Tools & Technologies
-MySQL
-SQL Queries
-MySQL Workbench
-Netflix Dataset (CSV)

📂 Dataset Information

The dataset contains details about Netflix content such as:

-Title
-Director
-Cast
-Country
-Release Year
-Rating
-Duration
-Genre
-Date Added

🔍 Key SQL Concepts Used
-SELECT Statements
-WHERE Clause
-GROUP BY
-ORDER BY
-Aggregate Functions
-Subqueries
-CASE Statements
-Joins
-Window Functions

📊 Project Insights
-Movies are more available on Netflix compared to TV Shows.
-The highest amount of content was released after 2015.
-Drama and Comedy are among the most popular genres.
-United States has the highest number of Netflix titles.
-TV-MA is one of the most common content ratings.

🚀 How to Run the Project
-Import the Netflix dataset into MySQL.
-Create a database and table.
-Run the SQL queries provided in the project.
-Analyze the generated insights and outputs.
